# Daily Job Library workflow

Run the daily job collection and application document workflow for the local JobEnhancingPipeline project at 8:30 a.m. and 3:30 p.m. Australia/Sydney time. Use the Sydney calendar date for this run. Treat the afternoon run as a fresh scan for later postings, preserving the morning results. Resume an unfinished earlier run where appropriate before starting a new scan. Do not resume a batch explicitly cancelled by the user. Read the project's current instructions and reuse the established collector, dedicated signed-in Chrome profile and local PostgreSQL Job Library. Use the current saved search keywords and filters for LinkedIn, SEEK and Indeed. Start at the first results page. Collect all supported pages for LinkedIn and SEEK and the supported results page for Indeed. Preserve the user's search filters. Reuse already-started daily runs when recovering a failure, avoid concurrent runs of the same workflow, and deduplicate repeated records. If a board is unavailable or requires sign-in, finish the other boards and report the specific blocker. For transient detail and pagination failures, use the site's normal posting or pagination controls for a bounded retry and verify identity and full job descriptions before saving. Complete the project's company review and resume matching with the current private resume master, using the established, authorized Codex scoring workflow. Verify saved counts and check for eligible unscored jobs before finishing. In Job Library, select the day's unapplied, non-excluded, eligible postings with a displayed score of at least 75. Deduplicate the same job across platforms, keep distinct role levels, and reuse existing document sets. Apply the applicant profile and check mandatory qualifications. Follow the current resume and cover letter guidance. Use the current single-column Word template and select verified bullets from the current Markdown master. Use the current Skills categories and a tailored two-page resume and one-page cover letter where applicable, render and inspect every deliverable, save each set to the corresponding capture for downloading, and confirm the download links. Prepare documents locally for review. Do not submit applications, send messages, or change application statuses. Summarize the day's counts by source, any failed or unresolved steps, and the Job Library links for generated documents in Chinese. Do not include private resume text in the summary.

## Execution

Run `./start_job.sh --source linkedin --source seek --source indeed --min-score 75` from the project root. Use the existing pipeline and its stage-specific prompt files rather than reconstructing the workflow in chat. The shared title filter must run before opening job details, researching companies, scoring or generating documents. Do not bypass it during retries. If recovering a partial run, resume only missing stages for its saved run IDs; do not repeat completed model calls or resume a user-cancelled batch. Do not change schedules during a run. Report actual completed counts and blockers in Chinese.
