# Project language

Use English for project documentation, source comments, command-line output, error messages, and interface text. Preserve original job posting content and other external data.

## Application documents

For a job-specific resume, select and lightly tailor verified bullets from `resume_master.md` using `storage/application_guidance.py`. When the applicant confirms a new responsibility or corrects an existing one, update the corresponding role in the master for future applications.

When preparing a cover letter, read the full job description, the confirmed resume and applicant profile, `storage/application_guidance.py`, and `templates/cover_letter.md`. Follow the evidence and rendering checks in the guidance before delivering the DOCX.
